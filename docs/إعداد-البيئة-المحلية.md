# إعداد البيئة المحلية (Neon)

## ملف `.env`

يُستخدم لتشغيل المشروع محلياً (`npm run dev` أو `netlify dev`). المتغيرات التي تبدأ بـ `VITE_` تصل للواجهة، والباقي للدوال فقط.

| المتغير | ماذا يفعل | من أين تأخذ القيمة |
|---------|-----------|---------------------|
| `VITE_AUTH_BACKEND` | يحدد نظام المصادقة: `neon` أو `supabase` | ضع `neon` لاستخدام Neon |
| `NETLIFY_DATABASE_URL` | رابط اتصال قاعدة بيانات Neon — تستخدمه دوال التسجيل والدخول | لوحة Neon → مشروعك → **Connection details** → انسخ **Connection string** |
| `AUTH_JWT_SECRET` | سِرّ لتوقيع رمز الجلسة (JWT) — يجب أن يكون طويلاً وغير متوقع | اختر بنفسك (32 حرفاً أو أكثر)، ولا ترفعه على Git |

## الخطوات

1. افتح [Neon](https://neon.tech) → مشروعك → **Connection details**.
2. انسخ **Connection string** (النسخة العادية أو Pooled).
3. في المشروع افتح `.env` واستبدل قيمة `NETLIFY_DATABASE_URL` بالرابط الذي نسخته.
4. استبدل قيمة `AUTH_JWT_SECRET` بسِرّ قوي (مثلاً سلسلة عشوائية 32 حرفاً).
5. احفظ الملف وأعد تشغيل `netlify dev` إن كان يعمل.

بعد ذلك تعمل صفحة «إنشاء حساب» وتسجيل الدخول محلياً ضد قاعدة Neon.

**ملاحظة:** لا ترفع ملف `.env` إلى Git (وهو مُدرج في `.gitignore`). على Netlify ضع نفس المتغيرات من لوحة الموقع (Environment variables).
